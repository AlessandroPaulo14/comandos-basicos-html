CONHECENDO A LINGUAGEM

O que é HTML?

HTML significa HyperText Markup Language, que em português significa Linguagem de Marcação de Hipertexto.

É uma linguagem utilizada para criar a estrutura de páginas da internet, permitindo adicionar textos, imagens, links, títulos e outros elementos.

O HTML é uma das principais ferramentas utilizadas no desenvolvimento de sites.

APRENDA NA PRÁTICA

Principais comandos HTML

Conheça algumas das tags mais utilizadas na criação de páginas da internet.

01

<h1>

Utilizado para criar títulos principais em uma página.

<h1>Meu título</h1>
02

<p>

Utilizado para escrever parágrafos e textos.

<p>Meu texto</p>
03

<img>

Permite adicionar imagens dentro de uma página.

<img src="foto.jpg">
04

<a>

Utilizado para criar links para outras páginas.

<a href="#">Link</a>
05

<br>

Utilizado para fazer uma quebra de linha.

<br>
06

<ul>

Cria listas sem numeração, utilizando marcadores.

<ul>...</ul>
07

<ol>

Cria listas organizadas com números.

<ol>...</ol>
08

<button>

Utilizado para criar botões interativos.

<button>Clique</button>

SEU PRIMEIRO PASSO

Por que aprender HTML?

Aprender HTML é importante para quem deseja conhecer o desenvolvimento web.

Com ele, é possível criar a estrutura de sites, organizar informações e apresentar conteúdos na internet.

Junto com o CSS, o HTML permite desenvolver páginas bonitas, organizadas e funcionais.
