Comandos Básicos de HTML

HTML é uma linguagem usada para criar páginas da internet.

Principais comandos:

1. Título

O comando <h1> é usado para criar títulos.

2. Parágrafo

O comando <p> é usado para escrever textos.

3. Imagem

O comando <img> é usado para colocar imagens.

4. Link

O comando <a> é usado para criar links.

5. Quebra de linha

O comando <br> serve para pular uma linha.

6. Lista

O comando <ul> cria uma lista.

Conclusão

Esses são alguns dos comandos básicos de HTML. Eles ajudam a criar e organizar páginas na internet.
