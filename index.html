O que é HTML?

HTML é uma linguagem utilizada para criar e organizar o conteúdo de páginas da internet. Com ela podemos adicionar textos, imagens, títulos, links e muito mais.

Principais comandos HTML

<h1>

É utilizado para criar títulos principais.

<p>

É utilizado para escrever parágrafos e textos.

<img>

É utilizado para adicionar imagens à página.

<a>

É utilizado para criar links para outras páginas.

<br>

É utilizado para fazer uma quebra de linha.

<ul>

É utilizado para criar listas sem numeração.

<ol>

É utilizado para criar listas numeradas.

<button>

É utilizado para criar botões.

Por que aprender HTML?

Aprender HTML é o primeiro passo para desenvolver sites. Ele permite organizar as informações e construir a estrutura de uma página da internet.
